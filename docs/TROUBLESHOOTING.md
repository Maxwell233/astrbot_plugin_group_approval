# 故障排除指南 (TROUBLESHOOTING.md)

---

## 1. 用户达到群等级却提示“未达到申请门槛”

### 现象
QQ 群内成员等级看似满足要求（例如头衔显示 LV15），但发送 `/申请使用` 时提示 `当前群申请门槛为 LV10，您当前群等级为 LV0`。

### 排查步骤
1. **核实 QQ 等级 vs 群成员等级**：
   - QQ 个人账号等级（太阳、月亮、星星）与 **QQ群成员活跃等级** 是完全不同的两个概念。
   - 准入插件严格检查 **群成员等级**，不读取账号等级。
2. **NapCat 本地缓存延迟**：
   - 插件在用户申请时已默认使用 `no_cache=True` 强制向腾讯服务器同步最新数据。
   - 若腾讯官方对新等级产生数分钟结算延迟，请稍后再次发送 `/申请使用`。
3. **群主关闭了群活跃等级展示**：
   - 若群主在 QQ 群设置中彻底停用了“群成员等级/头衔”功能，腾讯服务器会返回等级为空或 0。此时需在群设置中重新开启群等级功能。

## 2. 提示“获取群成员信息失败（错误代码：RETCODE_10001）”

### 现象
发送申请时提示获取信息失败。

### 原因与排查
- 用户已退群或被踢出，但消息因网络延迟残留。
- 协议端（NapCat）与腾讯服务器断开连接，或 QQ 账号触发了风控验证。
- 检查 NapCat 控制台日志是否有登录掉线或扫码提示。

---

## 3. 管理员收不到私聊申请提醒

### 排查步骤
1. **是否配置了 Owner 或 Reviewer QQ 号**：
   - 检查 WebUI 插件配置中 `owner_qq_ids` 或 `reviewer_qq_ids` 是否已填入正确的管理员纯数字 QQ 号。
2. **Bot 账号与管理员之间存在好友限制或临时会话风控**：
   - 腾讯可能限制未添加好友的用户之间的私聊发信。
   - **解决方案**：确保管理员与 Bot 账号互为 QQ 好友；或者在配置项 `fallback_group_id` 中配置审核专用工作群号，私聊失败时会自动转入备用群提醒。
3. **检查持久化发信队列表**：
   - 进入 WebUI 审计或查看数据库 `notification_outbox` 表，排查 `status` 是否为 `FAILED` 以及记录的 `last_error` 详情。

---

## 4. WebUI 看板无法打开或提示 404

### 排查步骤
1. 确认 AstrBot 当前版本是否在 v4.16.0 及以上。
2. 确认插件根目录下的 `pages/dashboard/index.html` 与 `views/dashboard/index.html` 均完整存在。
3. 若是在修改静态资源后未刷新，可在浏览器中强制刷新缓存（Ctrl + F5）。
