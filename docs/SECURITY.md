# 0.1.2 安全边界

- **受控入口**是 AstrBot 4.29.4 的 OneBot 默认聊天 Agent。兼容层在模型请求、原生会话历史和工具循环之前执行。非 QQ 平台、独立插件 Handler、插件主动 Provider 请求、GroupGuardian 和 LivingMemory 独立任务由各自配置控制。
- **Bot 隔离**使用已核验的 QQ 和 AIOCQHTTP 实例。等级查询显式按该 QQ 路由。授权唯一键为 Bot、用户、域。Dashboard 每次写入都重新核验所选 Bot，申请编号必须属于该 Bot。
- **管理身份**：QQ Owner、Reviewer 只能私聊执行 `/ga`。Dashboard 仅接受 AstrBot 认证后的配置管理员身份。QQ 角色不授予 Dashboard 身份或 AI 聊天权限。
- **资格与复核**：申请和审批强制向 NapCat 查询主群。有效缓存可用于原生聊天。新主群通过 Bot 自身成员查询后生效，配置版本递增并清空该 Bot 的旧快照。已存在的普通授权在下次使用时重新查询。查询错误暂时拒绝聊天，等级不足可暂停。
- **人工撤销**：独立持久限制与授权更新同事务。恢复和暂停使用现有 revision，自动审批和跨域创建前都检查限制。已撤销授权只有 Owner 明确重新授予后才可使用。
- **事务和隐私**：状态、授权、审计、结果通知入队在同一事务内。等待网络响应时不会持有 SQLite 写事务。审批信息通过私聊和已认证 Dashboard 显示，日志只保存管理记录与必要的审计数据。
- **豁免**：仅 Owner 可分别修改等级和成员身份豁免。单独的成员豁免不能使用过期等级缓存，用户退群后缺少可信等级时拒绝。明确双重豁免可跳过主群资格。
